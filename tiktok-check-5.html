TikTok Checker

Tempel link video TikTok untuk lihat info teknis & performanya.

Info teknis dibaca dari sampel kecil file video TikTok (tanpa download penuh), lalu dinilai AI Gemini (bukan file asli upload Anda — TikTok mengompres ulang saat upload). Data lain diambil dari halaman publik TikTok, bukan API resmi — kadang bisa gagal kalau videonya private/dihapus, atau TikTok mengubah tampilan halamannya.
